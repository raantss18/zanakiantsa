# 0042 — La même profondeur dans chaque domaine : apprendre, défi, carnet

- **Date** : 2026-11-03 · **Statut** : accepté (demande d'Antsa : ce qui est fait pour les échecs — jouer, garder,
  analyser, aller plus loin — « pour toutes les notions et composants de l'app »)
- **Accueil de domaine** (depuis « Tout explorer ») : Apprendre (la séance, reprise où l'enfant s'était arrêté), Le défi,
  Mon carnet ; plus les parties pour les échecs, les dessins pour le dessin. Les activités du jour ouvrent toujours la
  séance directement (un seul bouton pour l'enfant seul).
- **Défi** : 10 questions mêlées de ce que l'enfant a acquis (et du niveau juste en dessous de son âge), sans exemple ;
  score = réussites du premier coup ; record gardé par enfant et par domaine.
- **Journal** (base v4) : chaque question garde ses erreurs expliquées (ou, sans explication, le conseil de la
  compétence) et si c'était un défi. **Carnet** : état de chaque compétence en mots et en icône, réussite récente,
  erreurs qui reviennent. **Espace parent** : les erreurs qui reviennent sur 7 jours.
- **Plus loin** : anglais CE1 (le temps qu'il fait, « Simon says ») d'après le projet de programme LVER cycle 2 (juin
  2025). Sons : pas de niveau au-dessus de la GS tant qu'une source n'est pas trouvée (non vérifié).
