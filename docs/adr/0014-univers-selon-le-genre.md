# 0014 — Univers visuels selon le genre

- **Date** : 2026-11-02 · **Statut** : accepté (choix d'Antsa)
- **Décision** : 6 univers ; **garçon** : robots, voitures, espace ; **fille** : fées, poupées & mode, princesses &
  château. Le parent saisit le genre dans l'espace parent ; l'enfant ne voit **que** les univers de son genre et choisit
  parmi eux (`docs/design.md`).
- **Marques** : « Barbie » (Mattel) n'est pas reprise ; les univers poupées & mode et princesses ont des personnages et
  un nom à nous. Illustrations Twemoji (CC BY 4.0), attribution dans l'espace parent et `docs/licences.md`.
- **Contenu** : les phrases utilisent `{objet}`, `{objets}`, `{contenant}` fournis par l'univers ; la pédagogie est la
  même partout.
