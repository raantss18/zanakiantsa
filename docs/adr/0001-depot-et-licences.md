# 0001 — Dépôt public et licences

- **Date** : 2026-11-02 · **Statut** : accepté (licences confirmées par Antsa : « licence open source possible »)
- **Décision** : dépôt public `raantss18/zanakiantsa`. Code sous **Apache-2.0** (`LICENSE`) ; contenu original
  (`content/`) sous **CC BY-SA 4.0** ; contenu tiers sous sa propre licence, listé dans `docs/licences.md`.
- **Raison** : choix d'Antsa (dépôt public) ; licences reprises d'academik (`academik/LICENSES.md`) pour rester
  cohérent entre projets.
- **Conséquence** : aucune dépendance sous licence non OSI ; code AGPL (GCompris, Lichess) non intégré sans
  nouvel ADR, car il imposerait l'AGPL à l'app.
