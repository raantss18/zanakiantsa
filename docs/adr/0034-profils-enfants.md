# 0034 — Plusieurs enfants

- **Date** : 2026-11-03 · **Statut** : accepté (la fille d'Antsa, 7 ans, utilise aussi l'app)
- **Décision** : un profil par enfant (prénom facultatif, sur l'appareil seulement). Journal, séances et réglages
  (âge, genre, monde, voix, musique, marque-pages, questions récentes) appartiennent à l'enfant actif ; base v3, tout
  l'existant devient celui du premier enfant. À plusieurs, l'accueil demande « Qui joue ? » à chaque lancement ; le
  prénom en tête de l'accueil permet de changer. Ajout et renommage dans l'espace parent.
- **Point de départ selon l'âge** : les compétences des niveaux en dessous comptent comme acquises (5 ans : tout ;
  6 ans : dès la GS ; 7 ans : dès le CP ; 8 ans : dès le CE1). Elles restent jouables. Un vrai test de départ reste à
  faire.
