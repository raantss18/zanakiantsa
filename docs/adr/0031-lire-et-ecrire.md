# 0031 — Lire et écrire

- **Date** : 2026-11-03 · **Statut** : accepté (demande d'Antsa : « continue avec lire et écrire »)
- **Sources** : maternelle consolidée (« se préparer à apprendre à lire / à écrire », p. 12-20, https://eduscol.education.gouv.fr/sites/default/files/document/programme-cycle-1-consolide-127565.pdf) ; programme de
  français du cycle 2, BOENJS du 31/10/2024 (https://education.gouv.fr/sites/default/files/ensel135_annexe3.pdf).
- **Décision** : un domaine « Lire et écrire », 12 compétences dans l'ordre du programme : compter les syllabes
  (orales, mots ambigus écartés) ; rimes ; même premier son ; nom des lettres capitales ; capitale ↔ minuscule ; première
  lettre d'un mot (voyelles et consonnes qui se prolongent, pas les occlusives) ; minuscule ↔ cursive (lettres qui se
  ressemblent proposées exprès : b/d/p/q, c/e/o) ; tracer les capitales ; lire des syllabes (CP) ; tracer la cursive ;
  lire des mots transparents (CP) ; lire et comprendre une phrase (CE1). Le mot à lire n'est jamais dit ni étiqueté.
- **Écriture** : l'enfant repasse sur la lettre ; réussi si le tracé couvre ≥ 60 % de la lettre et en sort ≤ 35 %
  (deux images de 64 × 64 comparées sur l'appareil, sans modèle ni réseau). Cursive : police Playwrite France Moderne
  (SIL OFL), dessinée d'après l'écriture scolaire française. Le sens du tracé n'est pas vérifié (à faire).
- **Journée** : « lire et écrire » 3 jours sur 4 (ADR 0018 modifié).
