# 0015 — Récompenses : étoiles, autocollants, album

- **Date** : 2026-11-02 · **Statut** : accepté (choix d'Antsa : « plus de récompenses »)
- **Décision** : une **étoile** par bonne réponse (trouvée dans les 3 essais) ; toutes les **5 étoiles**, un
  **autocollant** de l'univers est gagné et rangé dans l'**album** (12 par univers). Fin de séance : étoiles du jour +
  nouvel autocollant révélé.
- **Garde-fous** (docs/pedagogie.md, ADR 0008) : rien ne se perd jamais (calculé depuis le journal) ; pas de monnaie,
  d'achat, de minuteur ni de classement ; le retour descriptif reste avant l'étoile.
- **Point d'attention** : Deci, Koestner & Ryan (1999) montrent que les récompenses tangibles **attendues** réduisent la
  motivation intrinsèque chez l'enfant. Les autocollants sont symboliques mais attendus : **à observer** lors de l'essai
  (`docs/essai-01.md`), et réversible si l'intérêt pour l'activité elle-même baisse.
