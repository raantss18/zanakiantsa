# 0019 — Nouveaux domaines et activités

- **Date** : 2026-11-03 · **Statut** : accepté
- **Domaines** (content/domaines.yaml) : le vivant (sens, déplacements, œufs ou petit porté, cycle de vie), les
  suites (motifs AB, ABB, ABC, évolutif), les sons (aigu/grave, fort/doux, long/court, lent/rapide), le dessin, les
  échecs (tour, fou, dame, roi, cavalier). Source : programme de maternelle consolidé (BO n° 41 du 31/10/2024 et
  n° 19 du 7/05/2026, https://eduscol.education.gouv.fr/sites/default/files/document/programme-cycle-1-consolide-127565.pdf),
  citation exacte dans chaque compétence ; échecs : FIDE Laws of Chess 2023, art. 3 (hors programme scolaire).
- **Activités** : `choisir` (question écrite + dite, 3 images, contenu dans `items`), `motif` (images de l'univers),
  `ecouter` (deux sons fabriqués par l'app, la carte qui sonne s'allume), `echecs` (attraper les étoiles ; un coup
  interdit = essai manqué, puis points sur les cases permises), `dessin` (feuille, 8 couleurs nommées, « Mes dessins »
  datés dans l'album, une étoile, jamais de note).
- **Images** : Twemoji (CC BY 4.0) ; pièces d'échecs Cburnett (CC BY-SA 3.0, `assets/echecs/LICENCE.txt`).
- **Reste à tester** : compréhension des questions de sons sans adulte ; le cavalier à 5 ans.
