# 0051 — Maia : un robot qui joue comme les humains, livré avec l'app

- **Date** : 2026-11-05 · **Statut** : accepté (demande d'Antsa : « Maia d'abord, le plus léger et performant »).
  Remplace la proposition de l'ADR 0047 pour Maia ; **Stockfish reste à faire** (réseau de 79 Mo).
- **Mesuré** : lc0 v0.32.1 compile pour Android arm64 avec le backend Eigen (aucune bibliothèque GPU), **2,5 Mo** une
  fois allégé ; les poids Maia-1 de 1100, 1500 et 1900 pèsent 1,3 Mo chacun. Sur l'émulateur (traduction ARM), un coup
  prend 0,12 à 0,17 s ; après 1.e4 e5, Maia-1100 joue 2.Cf3, puis 3.Fc4.
- **Pourquoi Maia-1 et pas Maia-2 (280 Mo) ni Maia-3 (AGPL, exclue par CLAUDE.md règle 7)**.
- **Décision** :
  - `liblc0.so` dans `jniLibs/arm64-v8a`, extrait sur le disque (`useLegacyPackaging`) : seul endroit d'où Android 10+
    laisse une appli lancer un programme. Recette : `tool/build_lc0.sh`, sources non modifiées.
  - Les poids sont des ressources de l'app, copiés une fois dans le dossier de l'app. Dialogue par UCI (`core/uci.dart`),
    un seul nœud : « a nodes limit of 1 is what we use » (README de Maia).
  - Dans « Contre le robot » : une 2e rangée « Maia 1100 / 1500 / 1900 », visible seulement si le programme est dans
    l'app (arm64). Le programme est arrêté en quittant la partie.
  - Garde-fous : coup refusé s'il n'est pas légal, moteur muet ou absent → le robot de l'app joue à la place.
- **Licences** : voir `docs/licences.md` (GPL-3, programmes séparés) et l'espace parent (crédits).
- **Reste à tester** : durée d'un coup sur la SM-X135G (l'émulateur ne la mesure pas) ; Maia avec un vrai enfant ;
  taille de l'APK (+ 6,3 Mo avec les trois niveaux).
