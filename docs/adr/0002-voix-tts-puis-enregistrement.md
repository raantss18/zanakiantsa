# 0002 — Voix off : synthèse d'abord, voix enregistrées ensuite

- **Date** : 2026-11-02 · **Statut** : accepté
- **Décision** : les prototypes utilisent la synthèse vocale de l'appareil ; toutes les consignes sont remplacées par
  des **voix humaines enregistrées** en français (ADR 0005) **avant** le premier essai avec des enfants (`docs/essai-01.md`).
- **Raison** : choix d'Antsa ; avancer sans bloquer sur l'enregistrement.
- **Contrainte** : chaque phrase dite a un identifiant stable dans le contenu (script d'enregistrement généré).
- **Reste à tester** : voix TTS française (et anglaise pour le thème anglais) réellement présentes sur la SM-X135G.
