# 0005 — Interface en français, anglais comme matière

- **Date** : 2026-11-02 · **Statut** : accepté
- **Décision** : l'application (consignes, voix off, espace parent) est **uniquement en français**. Le malgache est
  retiré du périmètre. L'**anglais** devient un **thème d'apprentissage** (langue vivante), enseigné depuis le français.
- **Raison** : choix d'Antsa, pour simplifier.
- **Conséquences** : une seule langue d'interface à enregistrer (ADR 0002) ; packs ML Kit `fr` (et `en` pour le thème
  anglais) ; l'opportunité « malgache natif » de `docs/teardown.md` n'est plus suivie.
- **Remplace** : la mention « français et malgache » de `CLAUDE.md`, `README.md`, `docs/vision.md`, ADR 0002.
